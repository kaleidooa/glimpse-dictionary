# Security

Report vulnerabilities through [GitHub private reporting](https://github.com/kaleidooa/glimpse-dictionary/security/advisories/new). Include the affected version, reproduction steps and impact. Please leave credentials, private page content, wordbook backups and gaze logs out of public issues.

Only the latest release is maintained. There is no paid bug bounty or response-time guarantee. Ordinary bugs and dictionary corrections belong in [Issues](https://github.com/kaleidooa/glimpse-dictionary/issues).
