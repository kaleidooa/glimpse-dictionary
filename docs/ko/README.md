# Glimpse

[English](../../README.md)

영어 단어의 한국어 뜻을 읽던 자리에서 확인하는 Chrome 확장입니다. 단어 위에 커서를 두고 **Alt+Q**를 누르면 뜻이 나타나고, 창을 닫을 때까지 해당 단어가 옅게 표시됩니다. 다시 보고 싶은 단어는 단어장에 저장할 수 있습니다.

51,109개 표제어를 기기에 포함해 오프라인으로 조회합니다. 없는 단어는 선택형 온라인 영영 사전으로 보충합니다. 화면 언어는 영어가 기본이며 한국어로 바꿀 수 있습니다.

텍스트를 드래그한 뒤 작은 버튼을 눌러도 됩니다. **뜻 보기**는 단어의 뜻을, **번역**은 영어 문장의 한국어 번역을 보여줍니다. 문장 번역은 지원하는 데스크톱 Chrome 페이지에서 기기 내 모델을 사용하며, 처음에는 모델을 내려받을 수 있습니다. 한 번에 최대 2,000자를 선택할 수 있고 선택한 글은 저장하지 않습니다. 기기 내 번역을 사용할 수 없으면 직접 눌렀을 때만 선택한 글을 보내는 Google 번역 링크를 제공합니다.

## 설치

1. [Releases](https://github.com/kaleidooa/glimpse-dictionary/releases)에서 ZIP을 내려받아 압축을 풉니다.
2. `chrome://extensions`에서 **개발자 모드 → 압축해제된 확장 프로그램 로드**를 선택합니다.
3. `manifest.json`이 들어 있는 폴더를 선택합니다.
4. 영어 웹페이지에서 단어 위로 커서를 옮긴 뒤 **Alt+Q**를 누르세요. 일반 웹사이트에서는 기본으로 바로 사용할 수 있습니다.

설치 폴더는 그대로 두세요. 새 버전으로 파일을 교체했다면 확장을 다시 로드하고 읽던 페이지도 새로고침해야 합니다.

확장 팝업과 **설정 → 단축키**에서 현재 조합을 확인할 수 있습니다. **단축키 변경**을 누르고 Chrome에서 Glimpse를 찾아 원하는 조합을 입력하세요. 새 설치 기본값은 Alt+Q이며, 기존 설치에서는 이전 단축키나 직접 지정한 조합이 유지될 수 있습니다. `chrome://extensions/shortcuts`를 직접 열어도 됩니다.

현재 GitHub에서 직접 설치하는 베타이며 Chrome Web Store에는 등록하지 않았습니다. Chrome 내부 페이지, PDF 뷰어, 이미지·캔버스 속 글자, 입력 영역은 지원하지 않습니다.

## 단어장과 설정

뜻에서 **Save word**를 누르면 기기 단어장에 저장됩니다. 검색, 익숙한 단어 표시, CSV 내보내기, JSON 백업·복원을 지원합니다. 조회만 한 단어는 저장하지 않습니다.

**Settings → Language → 한국어**에서 화면 언어를 바꿉니다. 설정에서 온라인 사전을 켜거나 전체 사이트 자동 사용을 끌 수 있습니다. 자동 사용을 끈 뒤에는 확장 팝업에서 개별 사이트를 추가할 수 있으며, Chrome 자체의 사이트 접근 설정이 우선합니다. 화면 언어와 관계없이 기기 사전의 뜻은 한국어입니다. 시선 추적은 별도 실험실에서 보정 후 사용할 수 있습니다.

## 개발

Node.js 24가 필요합니다.

```sh
npm ci
npm run dev
```

데모 주소는 `http://127.0.0.1:5173`입니다. 확장은 다음 명령으로 만듭니다.

```sh
npm test
npm run build:extension
npm run check:extension
```

Chrome에 `dist-extension`을 로드하세요. 패키징·벤치마크·시선 실험 방법은 [개발 문서](../DEVELOPMENT.md)에 있습니다. 버그나 PR에는 재현 방법과 실행한 검사를 적어 주세요. 사전 수정에는 재배포 가능한 출처가 필요합니다.
