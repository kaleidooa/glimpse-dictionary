# 무료 공개 베타에서 지속 가능한 제품으로

2026-09-12 기준. 아래 숫자는 실행 기준과 가격 실험의 가설이며 현재 사용자 수·매출·확정 가격이 아니다.

## 제품 방향

대상은 영어 기술 문서·기사·블로그를 자주 읽는 한국어 사용자다. 핵심 가치는 커서와 단축키 한 번으로 빠르게 뜻을 보고 읽기를 이어 가는 것이다. 계정 없이 기기에서 작동하는 영한 사전과 명시적으로 저장하는 단어장을 무료·오픈소스로 제공한다.

‘사전 조회’만 유료화하는 것은 경쟁력이 약하다고 판단했다. [Readlang](https://readlang.com/pricing)은 무료 단어 번역과 유료 문맥·학습 기능을 구분하며, 확인 시점 Premium은 월 $6 또는 연 $48이다. [Relingo](https://relingo.net/en/pricing)도 사전 조회를 무료로 제공하고 별도 번역 크레딧·확장 기능을 안내한다. 따라서 Glimpse의 유료 가설은 사전 자체보다 **복습을 이어 가는 편의**에 둔다. 이것은 제품 판단이며 실제 결제 수요를 검증한 결론은 아니다.

## 이번 공개 범위

- GitHub에 MIT 원본 코드, 별도 데이터 라이선스, 직접 설치할 ZIP, 문제 제보 양식과 CI를 공개한다.
- 무료: 커서 조회, 기기 영한 DB, 활용형·여러 뜻, 로컬 단어장, 익숙한 단어 표시, CSV/JSON 백업·복원.
- 실험: 별도 시선 추적 실험실. 정확도 보장이나 핵심 유료 혜택으로 홍보하지 않는다.
- 미제공: 결제, 구독, 클라우드 동기화, 예약 복습, 문맥 LLM, 자동 이용 통계. 작동하지 않는 결제·후원 버튼을 제품에 넣지 않는다.

## 첫 4주 실험

1. **첫 사용 10명 관찰:** 설치에서 첫 뜻 확인까지 2분 이내인지, 사이트 권한과 단축키 설명만으로 진행 가능한지 확인한다. 제보는 동의한 사용자에게 최소 정보만 받는다.
2. **독해 200개 독립 사례:** 수정에 쓰지 않은 기사·기술 문서에서 표본을 고정한다. 단어 탐지, 원형, 유용한 뜻 포함, 첫 뜻 적합성, 누락을 따로 평가한다. 원문 전체를 자동 수집하지 않는다.
3. **7일 뒤 재사용 확인:** 자원한 사용자 중 몇 명이 다시 쓰고 단어장을 열었는지 직접 확인한다. 설치 수·GitHub Star를 활성 사용자 수로 간주하지 않는다.
4. **가장 반복되는 문제 하나 해결:** 미등록 단어, 설치 마찰, 뜻 품질, 복습 수요 중 실제로 자주 관찰된 문제를 우선한다.

출시 판단 기준의 초안은 첫 사용 성공 8/10 이상, 지연 없는 로컬 조회, 데이터 유실·불필요한 외부 전송 0건이다. 작은 표본이므로 통계적 성능 보증으로 쓰지 않는다. 그 뒤 Chrome Web Store 공개 베타로 설치 경로를 간소화한다.

## 수익화 순서

1. 자발적 후원 수요가 생기면 소유자가 운영할 후원 계정을 연결한다. 현재 수납 계정이나 결제는 설정하지 않았다.
2. 반복 사용자가 복습·동기화를 원하면 예약 복습, 여러 기기 동기화, Anki 연동 같은 부가 서비스의 유료 의향을 확인한다. 단어장을 인질처럼 잠그지 않고 기존 CSV/JSON 내보내기를 유지한다.
3. 월 3,000원 또는 연 24,000원은 **비교할 가격 가설**이다. 예를 들어 월 결제 30명은 수수료·세금·서버비 이전 월 9만원이다. 매출 예측이 아니며 이 가격으로 판매를 시작하지 않았다.
4. 실제 운영자, 지원 연락처, 결제 사업자·정산, 환불·해지 안내, 데이터 처리와 운영비가 정해진 후에 결제를 구현한다. 장기 동기화 서비스를 일회성 평생 이용권으로 먼저 약속하지 않는다.

자동 광고, 사용자 데이터 판매, 원문 자동 수집은 현재 제품 방향에 넣지 않는다. 원본 코드의 MIT 공개와 별도 운영 서비스의 유료화는 구분하며 데이터의 CC BY-SA/MPL 조건은 계속 따른다.

## Chrome Web Store 단계

[공식 등록 안내](https://developer.chrome.com/docs/webstore/register)에 따르면 개발자 이메일, 개발자 등록과 일회성 등록비 처리가 필요하다. 계정 선택·결제·계약 동의는 소유자가 확인해야 하는 단계다. 이번에 별도 비용을 지출하거나 스토어 심사에 제출하지 않았다.

[스토어 정책](https://developer.chrome.com/docs/webstore/program-policies/policies)에 맞춰 설명과 실제 기능, 단일 목적, 사이트 권한 사유, 공개 개인정보 안내, 시선 베타 데이터 처리를 일치시킨다. 제출용 문구와 테스트 절차는 [STORE-LISTING.md](STORE-LISTING.md)에 있다. 스토어 승인을 받았다고 표시하거나 일반 웹페이지의 모든 렌더러에서 작동한다고 주장하지 않는다.
