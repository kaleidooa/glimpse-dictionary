# Chrome Web Store 제출 초안 · Glimpse 0.4

이 문서는 제출 준비 자료다. 아직 Chrome Web Store에 등록·제출·승인되지 않았다.

## 제품 정보

이름: **Glimpse — 커서 영한 사전**

짧은 설명: **영어 단어에 커서를 두고 단축키를 누르세요. 5만 개 이상 표제어의 한국어 뜻을 기기에서 조회하고, 고른 단어만 단어장에 저장합니다.**

상세 설명:

> 영어 글을 읽다가 모르는 단어를 만났을 때, 커서를 두고 Alt+Shift+D를 누르세요. 단어 옆에서 한국어 뜻을 확인할 수 있습니다.
>
> • 51,109개 공개 사전 표제어와 기본 교정 뜻을 기기에서 조회합니다.
> • went → go처럼 활용형을 처리하고 품사·여러 뜻·출처를 보여줍니다.
> • 직접 저장한 단어를 단어장에서 다시 보고, 학습 상태를 표시할 수 있습니다.
> • CSV 내보내기와 JSON 백업·복원을 지원합니다.
> • 사용할 사이트를 직접 고르고, 온라인 영영 사전은 필요한 경우에만 켭니다.
> • 시선 추적은 별도 실험실 BETA에서 직접 카메라를 연결할 때만 실행합니다.
>
> 기본 커서 조회에는 계정·카메라·API 키가 필요하지 않습니다. 일반 조회의 문장·방문 주소·이력을 저장하지 않습니다. 저장 버튼을 누른 단어와 뜻만 해당 기기에 보관합니다.
>
> Chrome 내부 페이지, 웹 스토어, PDF 뷰어, 이미지·캔버스 속 글자, 편집 가능한 영역과 일부 특수 렌더러는 지원하지 않습니다. 공개 사전에는 누락과 부정확한 뜻이 있을 수 있으며 시선 기능의 정확도를 보장하지 않습니다.

단일 목적: **영어 웹 콘텐츠를 읽는 동안 단어의 한국어 뜻을 확인하고, 사용자가 고른 단어를 다시 학습하도록 돕습니다.**

## 권한 설명

| 권한 | 실제 용도 |
|---|---|
| activeTab | 사용자가 ‘이번 탭에서 사용’을 누른 활성 페이지에 리더를 적용 |
| scripting | 허용된 페이지에서 커서 주변 단어를 찾고 뜻 팝업을 표시 |
| storage | 사이트 허용·사전 설정, 사용자가 저장한 단어장 보관 |
| 선택형 HTTP/HTTPS 호스트 | 사용자가 고른 사이트 또는 전체 일반 웹사이트에서 자동 사용. 보조 사전은 해당 API 호스트를 따로 허용 |

카메라 코드는 별도 실험실에만 있고, 사용자의 직접 연결과 브라우저 권한 승인이 필요하다. 원격 실행 코드는 가져오지 않으며 모델/WASM/사전 데이터는 패키지에 포함된다.

## 데이터 공개 항목 확인

‘서버에 업로드하지 않는다’는 이유로 모든 데이터 항목에 일괄 ‘수집 없음’을 체크하지 않는다. 아래 처리 내용을 현재 대시보드의 정의에 맞춰 소유자가 확인한다.

- 단축키 조회 시 사용자가 허용한 웹페이지의 단어 주변 텍스트를 일시적으로 처리.
- 사용자가 저장 버튼을 누르면 단어·뜻·품사·공개 사전 출처·시각·학습 상태를 로컬에 보관.
- 보조 사전을 켠 경우 미등록 영어 단어와 API 요청의 IP 주소가 외부 제공자에 전달.
- 시선 베타는 로컬 카메라 처리, 얼굴·눈 특징과 실험 문장·시선 기록을 로컬에 보관.
- 광고, 판매, 자동 분석 수집, 클라우드 동기화, 사용자 계정 없음.

## 리뷰어 확인 절차

1. 설치하면 처음 사용 안내가 열린다. 이때 카메라·전체 사이트 권한 요청이 자동으로 뜨지 않아야 한다.
2. 팝업의 직접 조회에서 serendipity, went, bank를 조회한다. 온라인 설정을 꺼도 한국어 뜻이 나와야 한다.
3. 공개 HTML 기사에서 ‘이번 탭에서 사용’ → 단어 위 커서 → 단축키를 확인한다. 스크롤하면 팝업이 닫힌다.
4. 저장 버튼을 누르고 내 단어장에서 확인한다. 검색, 익숙한 단어 표시, CSV/JSON 내려받기, JSON 가져오기와 삭제를 확인한다.
5. 설정에서 사이트 권한과 보조 사전을 켜고 끈다. 권한 취소를 거부/허용하는 경로를 모두 확인한다.
6. 시선 실험실은 직접 웹캠을 연결했을 때만 작동하며 나가면 카메라가 중단되는지 확인한다.

## 제출 직전 소유자 확인

개발자 계정·이메일·등록비, 공개 운영자 정보, 실제 화면 스크린샷과 최종 설명, 현재 스토어 데이터 공개 항목과 필요 자산 규격을 확인한다. 결제는 없는 무료 베타로 제출한다. 스토어 링크가 발급된 뒤에만 제품에 ‘Chrome에 추가’ 버튼을 연결한다.
