Glimpse는 계정, 이용 통계, 광고, 자체 서버를 사용하지 않습니다. 운영 저장소는 kaleidooa/glimpse-dictionary입니다.

사전과 단어장

허용한 페이지에서 마지막 커서 위치를 메모리에 두고 단축키를 누를 때 주변 텍스트를 읽습니다. 텍스트를 선택하면 작은 버튼을 표시하기 위해 선택 범위를 읽으며, 버튼을 눌러야 조회합니다. 이동 경로, 조회 이력, 본문, 방문 주소는 저장하지 않습니다. 입력창과 편집 영역은 제외합니다.

기기 사전은 로컬 파일에서 읽습니다. 단어장에 저장을 누르면 단어, 원형, 최대 3개 뜻, 품사, 출처 링크, 라이선스, 저장 시각과 학습 상태를 chrome.storage.local에 저장합니다. 한도는 1,000개 또는 약 4MB입니다. 문장·방문 주소·카메라 데이터는 단어장에 넣지 않습니다.

개별 삭제, CSV·JSON 다운로드, JSON 가져오기를 지원합니다. 가져오기는 기기에서 처리하며 기존 항목을 유지하고 빠진 단어만 추가합니다. 자동 동기화·업로드는 없습니다. 확장을 제거하면 저장소가 삭제되지만 다운로드한 백업은 남습니다. localhost 데모는 별도의 localStorage를 사용합니다.

선택형 온라인 조회

기본으로 꺼져 있습니다. 설정을 켜고 Chrome에서 접근을 허용한 경우 기기 사전에 없는 영어 단어 하나를 HTTPS로 api.dictionaryapi.dev에 보냅니다. 문장·방문 주소·쿠키·referrer는 보내지 않습니다. 제공자에는 IP와 요청 시각이 보이며 그 서버의 처리는 Glimpse가 통제하지 않습니다. Free Dictionary API 안내를 참고하세요.

연결 검사는 고정 단어 serendipity를 보냅니다. 온라인에서만 찾은 단어를 저장할 때 같은 조회를 반복할 수 있습니다. 설정을 끄면 추가 온라인 요청을 중단합니다.

문장 번역

번역을 누르면 선택한 영어 텍스트를 최대 2,000자까지 Chrome의 기기 내 Translator API로 처리합니다. 처음에는 Chrome이 언어 모델을 내려받을 수 있습니다. Glimpse는 해당 글을 번역 서버로 보내거나 선택한 글·번역 결과를 저장하지 않습니다. 결과 창을 닫으면 진행 중인 번역을 취소합니다. 사용 가능 여부는 브라우저와 페이지 권한에 따라 다릅니다.

기기 내 번역에 실패하면 선택형 외부 링크인 Google 번역으로 보내기를 제공합니다. 직접 누르면 선택한 글을 Google에 보내고 새 탭을 엽니다. 글이 URL에 포함되므로 브라우저 방문 기록에 남을 수 있습니다. Google은 일반 웹사이트 방문 정보도 받으며 자체 정책에 따라 글을 처리합니다. Glimpse는 이 링크를 자동으로 열지 않습니다.

설정과 권한

화면 언어, 온라인 조회 여부와 허용 사이트 목록은 기기에 보관합니다. 기본 화면 언어는 영어입니다.

설치할 때 HTTP/HTTPS 웹사이트 접근 권한을 요청합니다. 자동 사용은 기본으로 켜져 있어 각 페이지에서 첫 단축키나 텍스트 선택부터 사용할 수 있습니다. 페이지 리스너는 마지막 커서 위치와 선택 범위를 메모리에 잠시 보관합니다. 본문을 훑거나 단어를 자동 조회하지 않습니다. activeTab과 scripting은 확장 팝업에서 탭을 활성화할 때도 사용합니다.

전체 사이트 자동 사용을 끄면 실행 중인 리더를 중단하고 개별 사이트 목록을 비웁니다. 이후 확장 팝업에서 원하는 사이트만 추가할 수 있습니다. 저장한 단어와 온라인 사전 설정은 유지합니다. 이 스위치는 Chrome의 접근 권한을 철회하지 않으며, 권한 자체는 Chrome 확장 설정에서 관리합니다.

시선 실험실

웹캠 연결을 누르고 권한을 허용할 때만 카메라를 켭니다. 영상은 기기에서 처리하며 저장·전송하지 않습니다. 연결을 끊거나 실험실을 닫으면 카메라를 중단합니다.

눈·얼굴 특징 수치, 시선 좌표·시각, 글과 문장, 보정, 목표·결과, 화면 크기와 스크롤 상태는 실험실의 localStorage에 저장하며 내보내기에도 포함합니다. 실험 기록 삭제로 기록과 보정을 지웁니다. 일반 웹페이지에서는 시선 정보를 수집하지 않습니다.

개발자가 따로 실행한 localhost 실험실에 OpenAI 키를 설정한 경우에만 미등록 단어와 해당 문장을 OpenAI로 보낼 수 있습니다. 제공자의 이용 조건과 API 요금이 적용됩니다. Chrome 확장은 이 요청을 하지 않습니다.

링크와 문의

출처와 GitHub 링크는 직접 누를 때 열립니다. GitHub 이슈·댓글은 공개되므로 비공개 글이나 내보내기 파일을 첨부하지 않아도 됩니다. 보안 문제는 비공개 보고를 이용하세요.

사용자 데이터는 Chrome Web Store User Data Policy의 Limited Use 요구사항에 따라 여기에 설명한 기능에만 사용합니다. 판매하거나 광고에 쓰지 않습니다. 처리 방식이 바뀌면 이 문서와 제품 안내에 반영합니다.
