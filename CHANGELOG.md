# Changelog

## 0.4.0 — 2026-09-12 · Public beta

- First-use guide with working dictionary examples, permissions help and a path to the reading demo.
- Compact extension popup; site permissions, optional online lookup and experimental eye tracking organized in a dedicated settings page.
- Explicit local word saving; search, learning/known states, deletion, CSV export and JSON backup/merge restore. No automatic lookup history, sentence or visited URL storage.
- Trusted-context storage, private wordbook message boundaries, bounded imports and serialized writes.
- More readable dictionary popup text, loading/error feedback and application error recovery.
- MIT licensing for original code, separate data notices, contribution and security guidance, CI and reproducible release checks.

## 0.3.0

51,109 offline English-to-Korean public headwords, WordNet inflections, multiple senses and attribution, optional online diagnostics, dictionary coverage and timing reports.

## 0.2.0

Chrome Manifest V3 cursor dictionary, Alt+Shift+D, optional site permissions, scroll handling, and eye-tracking experiments separated into a beta lab.
